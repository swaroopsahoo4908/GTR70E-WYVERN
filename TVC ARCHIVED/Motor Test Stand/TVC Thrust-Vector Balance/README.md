# Servo TVC Test Stand, 3-Axis Load Balance

Printable **PETG-CF** parts for the servo-gimbal thrust-vector balance (RQ1/RQ5, see
`WYVERN_E4_GSE_TestStands.md` §2). Resolves the full commanded thrust vector via one axial (Z)
and two lateral (X, Y) strain-gauge load cells through flexures.

- `TVC_balance_base.*`, fixed base with the 3 load-cell pedestals + 4 corner mounting bosses.
- `TVC_balance_thrust_block.*`, motor + gimbal mount, doubles as the gimbal's pitch-axis trunnion
  mount for this bench rig (through-holes matching the gimbal's 3.2mm pivot bore, see
  `3D parts/_generator/gen_rocket4.py` `gimbal()`/`tvc_balance()`).
- `TVC_balance_flexure_template.*`, spring-steel flexure cutting/bending guide (not a functional
  plastic part).
- `TVC_balance_hx711_mount.*`, HX711 breakout mounting plate.

Instrumentation: **5 kg axial + 2x 1 kg lateral** strain-gauge load cells, 3x HX711, read by one
of the three custom RP2350 flight-computer PCBs at 80 SPS (`WYVERN_E4_GSE_TestStands.md` §2).
The magnetic-solenoid TVC stand (`WYVERN Project/3D parts/MTVC/`) is a physically separate rig,
not generated by this script.

Generated by `../../3D parts/_generator/gen_rocket4.py`. Fastener standard: M3 heat-set brass
inserts (4.2mm pilot, 8mm boss OD). Load-cell and HX711 hole spacing are TYPICAL-CLASS figures
for the specific Adafruit parts in the BOM, verify with calipers against the actual hardware
before the final print (see the generator's module docstring and `CONFLICTS.md` #9).
