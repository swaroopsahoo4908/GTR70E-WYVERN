# Data

Test and flight datasets (released openly at program conclusion):

- Wind-tunnel runs — fin profile + material + coating, straight-on and 0.5° deflection sweeps (RQ1/RQ2).
- Motor static fires — thrust-vs-time and total impulse (RQ3).
- Material erosion — E16-4 plume mass-loss / profilometry (RQ3).
- Flight data — SD-NAND + microSD onboard logs, retrieved post-flight (RQ4). No radio downlink.
